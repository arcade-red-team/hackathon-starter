# hackathon-starter

Template for every arcade-red-team hackathon entry. Copy, rename, build ONE happy path perfectly.

Playbook:
1. Idea first - fresh/clever, X-viral potential
2. Scope to deadline - cut everything not judged
3. Polish extreme - small surface, perfect details
4. Fully functional - no faked core features
5. Packaging = 50% - video + README from day 1
6. Agents build - solo + AI

Submission checklist:
- Public repo, MIT license, README setup <3 steps
- Live demo URL works for judges without login
- Demo video <=3 min: problem 20s, insight 20s, working product 60s, market 30s, team 20s
- Screenshots/logo if required
- Submit 24h before deadline
- Disclose prior work honestly

Ship small, ship perfect.
